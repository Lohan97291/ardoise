## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Assistant IA Ardoise

Pour activer `Plume d'Ardoise` et la génération de fiches de prep :

1. Ouvre le fichier `.env.local`
2. Renseigne `OPENAI_API_KEY`
3. Laisse `OPENAI_MODEL=gpt-4o-mini` ou remplace-le si besoin
4. Relance l'application

Un modèle prêt à remplir est disponible dans `.env.example`.
